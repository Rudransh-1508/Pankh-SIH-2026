# DigiLocker Documents are stored by reference; only Uploaded Documents are stored as files

Every stored copy of an ST certificate or Aadhaar is a liability under the Digital Personal Data Protection Act 2023. For Documents DigiLocker holds, Pankh stores only the DigiLocker reference, the Proof and a hash, and fetches the Document when needed. Uploaded Documents are encrypted and kept in private object storage with short-lived links and a retention schedule. Production uses S3 (cheaper per GB than a VM disk and managed); local development uses SeaweedFS or a plain directory through the same interface (see ADR 0012).
