# The language model is provider-neutral and never receives whole documents or Aadhaar numbers

Claude is ruled out for cost, and the right cost-efficient provider for Indic, multi-step agent work must be chosen by measurement, not guesswork. The backend talks to models through one provider-neutral interface, so the provider can be changed without touching Agents. Whatever the provider, a model receives only the specific fields a task needs, never whole documents or Aadhaar numbers, because student data may otherwise leave India.
