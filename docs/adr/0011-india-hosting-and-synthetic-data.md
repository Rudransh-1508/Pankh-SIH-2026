# All data is hosted in an AWS India region, and development uses only synthetic students

Government deployments and the Digital Personal Data Protection Act 2023 point to keeping student data in India, so all storage and processing run in an AWS India region. The ministry's published selection lists contain real students' names; Pankh never loads personal data from them. Test and demo students are generated synthetically, and only aggregate public figures (such as state-wise beneficiary counts) are used as real data.
