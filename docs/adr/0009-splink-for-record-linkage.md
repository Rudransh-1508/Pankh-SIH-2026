# Record linkage uses Splink with Indic name normalisation, never Aadhaar joins

Finding the same person across scholarship records, UDISE+, APAAR and OTR cannot rely on Aadhaar numbers, which may not be used for this purpose, and tribal names vary widely in spelling, script and order. Splink gives probabilistic matching with per-field match weights that explain each Record Link to a Reviewer. We add Indic script normalisation, transliteration and sound-alike keys on top.
