# Agents collect, explain and chase; engines decide; humans approve consequential actions

Language models can be wrong, and government decisions need an audit trail. No Agent writes an eligibility or verification outcome: only the rules engine and verification layer do, and Agents call them as tools and repeat their results with sources. Any action with consequences (contacting an official, filing a grievance, submitting an Application) needs explicit approval from the Student or a Reviewer. Every Agent action is logged with its inputs and the Consent it relied on.
